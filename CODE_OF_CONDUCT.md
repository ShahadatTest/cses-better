# Code of Conduct

## Our standard

CSES Better is an independent project maintained for people who practice programming and contribute to software. Treat everyone in project spaces with respect and make room for people with different backgrounds, experience levels, communication styles, and access needs.

Examples of behavior that helps this community include:

- Giving feedback about the work rather than attacking the person.
- Explaining disagreements and accepting good-faith correction.
- Sharing enough context to make bug reports and review comments useful.
- Respecting privacy, attribution, and the time of contributors.

Unacceptable behavior includes harassment, discriminatory or sexualized language, threats, deliberate intimidation, personal attacks, doxxing, and publishing another person's private information or credentials without consent. Repeated disruptive behavior, including spam or knowingly abusive review comments, is also not welcome.

## Where it applies

This code applies in this repository's issues, pull requests, discussions, and other project spaces, including when someone is representing the project in a public setting.

## Reporting and enforcement

If you experience or witness unacceptable behavior, contact the repository maintainers privately through a contact route listed on the repository owner's GitHub profile, if one is available. If you cannot find a private route, open an issue asking only for a private way to contact the maintainers. Do not include names, allegations, screenshots, or other sensitive details in that public issue.

Maintainers will review reports and may edit or remove content, close contributions, restrict participation, or block accounts according to the severity and pattern of behavior. They should explain moderation decisions when doing so is safe and practical. This project does not promise a response time or a particular outcome.

For security vulnerabilities, follow [SECURITY.md](SECURITY.md) instead. Do not use public issues for vulnerability details or secrets.
